About Me

I'm a Product Engineer and Full-Stack Developer based in Gorakhpur, India, currently working remotely with GetPost Labs (Brisbane, Australia). I design, build, and maintain scalable backend services and RESTful APIs using Java, Spring Boot, and MongoDB for the Lex-AML platform.

My background spans the full software lifecycle — from product development and API integration to code reviews and deployment within Agile teams.
